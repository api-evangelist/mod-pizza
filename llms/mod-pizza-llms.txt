# MOD Pizza

> MOD Pizza is a Seattle-based fast-casual restaurant chain serving individually sized,
> made-to-order artisan-style pizzas and salads at one fixed price regardless of topping count.
> MOD Pizza publishes NO public API. It has no developer portal, no API reference, no OpenAPI,
> AsyncAPI, GraphQL SDL, Protobuf, WSDL or MCP server on any host it controls. Its digital guest
> surfaces run on licensed third-party SaaS. This file is GENERATED by API Evangelist from the
> company's public website; it is not published by MOD Pizza.

## Developer surface

- No developer program. Probed 2026-08-25: modpizza.com, orders.modpizza.com and
  locations.modpizza.com return 404 (or an SPA catch-all redirect) for /openapi.json,
  /swagger.json, /api-docs, /llms.txt, /graphql and every /.well-known/ path.
- No first-party SDK or client library is published on npm, PyPI, RubyGems, crates.io or NuGet.
- No public code: github.com/MOD-PIZZA is a real MOD Pizza organization but has 0 public
  repositories.

## Third-party platforms MOD Pizza consumes (these APIs belong to the vendors, not to MOD Pizza)

- Online ordering: Koala (orders.modpizza.com is a Koala-powered Next.js storefront calling
  api.koala.io). The contract belongs to Koala, not MOD Pizza.
- Loyalty / mobile app: Punchh (the iOS and Android "MOD Pizza" apps ship under the
  com.punchh.mod bundle identifier). MOD Rewards is a Punchh program.
- Store locator: Yext (locations.modpizza.com is served from Yext's pages CDN).
- Delivery: fulfilled through third-party marketplaces, notably DoorDash.
